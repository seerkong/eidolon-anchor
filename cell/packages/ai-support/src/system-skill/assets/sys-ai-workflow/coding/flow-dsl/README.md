# Flow DSL reference map

本目录从 depa-flows 文档裁剪出 AI Workflow 所需的规范骨架。阅读顺序固定：

`L1 foundation` → `EagerDataFlow / WorkCtrlFlow substrate` → `AIWorkflowAppBundle` → `AICtrlWorkflow / AIDataWorkflow profile`。

目录阅读顺序是 `foundation` → `std/eager-data-flow | std/work-ctrl-flow` → `spec/flow-core` → substrate spec → `spec/ai-workflow`。

这里是 coding stage 的规范 authority；其他 DevOps stage 不加载此目录。出处与裁剪范围见 `provenance.xnl`。
