# Deploying protocol

1. Load `sys-eidolon-anchor-run` and its `operations/index.md` through the generic `Skill` tool.
2. Prefer the exact publication receipt entrypoint; resolve only an actually missing identity.
3. Load the exact instance/binding operation resource and call its native tools.
4. Preserve the instance and binding receipt, then transition to `operating` only if execution was independently requested.

Do not rescan known Types or instances and do not start a run before an instance identity exists.
