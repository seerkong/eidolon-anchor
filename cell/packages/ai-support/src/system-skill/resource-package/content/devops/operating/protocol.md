# Operating protocol

The stage context already contains the Run root and operations index; do not load them again. Select the exact start or wait-resume operation resource from current instance/run facts. For an explicitly authorized first execution with no instance, use one generic `Skill.resources` batch for `operations/resolve-entrypoint.md`, `operations/instance-binding.md`, `operations/start.md`, and `operations/agent-execution.md`, then create the instance and start it. With an existing instance and execution authorization, invoke the corresponding native tool once and preserve its run receipt. With a terminal result, deliver it or move to `monitoring` only for requested evidence detail.
