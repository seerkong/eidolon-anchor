# Planning protocol

1. Inspect only the exact existing fact needed to distinguish create, edit, or observation.
2. State the target, boundaries, input/output, participants, failure policy, evidence, and authorization gates.
3. Ask only for missing information that would change topology or fact ownership.
4. Select the next explicit stage.

For a confirmed fresh create, choose `coding` immediately and do not add catalog/list/summary discovery. Domain wording is evidence for model reasoning, never a host routing rule.
