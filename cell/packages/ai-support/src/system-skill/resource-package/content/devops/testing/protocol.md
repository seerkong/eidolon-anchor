# Testing protocol

After the final mutation, call `WorkflowPreparePublication` once with the exact `session_id`. Consume its component-derived ResourcePackage load/registry/App/Agent/Material/profile/freeze/build receipts, or the legacy VFS proof set when that mode is explicit. Do not submit an acceptance policy or treat static projection as real execution.

On success, request the typed ready receipt through `WorkflowCompleteAuthoring`; on a deterministic diagnostic, return to `coding` for a new revision. A ready receipt does not imply publication authorization or execution authorization, and this stage never starts a run.
