# AT3 兼容、成本与验收

> 优先级 2：成本与进度不得推翻 AT1/AT2。跨维冲突先保留用户明确要求，再按各自职责裁决。

## 不变量

1. **旧行为不退化**：既有 CLI 入口、argv/JSON/退出码契约、旧工具与既有 Workflow 实例在拆分期间保持可用。新资源式入口不得让旧路径无法启动。
2. **验证强度不降**：不为节省 token 关闭检查、降低已配置轮数、复用本应 fresh 的语义 verdict，或删掉必要的负例。
3. **上下文经济性**：Skill 根只提供入口与路由，按任务加载相关操作与精确契约。父 Agent 与 Worker 各自取得所需知识与能力，不假定继承正文；记录实际 provider 可见内容与版本，不要求每轮重复加载全部文档。
4. **证据分层**：Skill 已安装、已加载、provider 可见、公开路由成功、业务结果正确分别判定，不用部分成功代表整体通过。模型自述、CLI stdout 中的 ID/`Completed` 不等于业务通过。
5. **隔离验证**：历史升级、安装与真实 E2E 在隔离 workspace/home 下验证；保护开发者当前真实 global 安装与既有 dogfood 状态不被静默覆盖。
6. **授权边界**：真实 provider 调用、npm 发布、覆盖本机全局安装、变更受保护面是各自独立的 checkpoint；预算、模型、请求次数与取消策略在运行前具象化，超出现有授权时先提决策。

## 排除集

- 以「离线测试通过」完成需要真实 provider 的验收项。
- 把本地 pack / 未发布候选 / 源码路径消费写成「已发布公共包」。
- 预算耗尽或传输失败写成成功；无隐式自动重试。
- 为让新入口通过而修改被测 Agent 的验收标准或框架源码。

## 与 depa-codument 的关系

depa-codument 的 `accuracy-and-context` 吸引子与 `clone-modes`/`global-skill-app` 设计是同构外部参照：其「无本地 material / 越界 / symlink / JSON 与正文混淆场景失败关闭」的要求可直接借鉴。它的实施状态与验收结论**不**构成 Eidolon 的事实。
